# Contact Xoeris

Horizone IDE is made by **Xoeris**. The best way to reach us is through this repository on GitHub.

| I want to… | Where |
|---|---|
| Report a bug | [Open an issue](https://github.com/Xoeris/Horizone-IDE/issues/new). Include your Horizone IDE version (*Settings → About*), what you did, what you expected and what happened. For language-server problems, attach `%TEMP%\HorizoneIDE-lsp.log`. |
| Suggest a feature | [Open an issue](https://github.com/Xoeris/Horizone-IDE/issues/new) describing what you'd like and why. |
| Ask a question | Check the [Help](HELP.md) first, then [open an issue](https://github.com/Xoeris/Horizone-IDE/issues/new). |
| Ask about the License or Terms | [Open an issue](https://github.com/Xoeris/Horizone-IDE/issues/new). |
| Make a privacy or account request (access, correction, deletion) | [Open an issue](https://github.com/Xoeris/Horizone-IDE/issues/new) saying what you need, **without** posting personal details publicly. We will reply there and arrange a private channel to verify it's you. |
| Request source code of a GPL component | [Open an issue](https://github.com/Xoeris/Horizone-IDE/issues/new) naming the component and version (see the [Open Source Software Statement](OPEN-SOURCE.md)). |

Please don't post passwords, API keys, one-time codes or private code in issues. They are public.
